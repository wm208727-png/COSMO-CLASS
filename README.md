### 🪐 MAIN PROJECT - Planet X Hunter (SPHEREx Blink Comparator)

NASA SPHEREx Mission (Launched 2025) scans the whole sky every 6 months in infrared. If Planet X exists, it will MOVE between Survey 1 and Survey 2.

This app is a functional **simulation** of that methodology, inspired by how Clyde Tombaugh discovered Pluto in 1930.

**How it works:**
1.  Uses Real NASA APOD API for Live Background
2.  Canvas renders 200 stars + a simulated Planet X
3.  **Blink Mode (400ms):** Survey 1 <-> Survey 2 auto blinks. Planet X jumps (Red Dot X:200 Y:170)
4.  **BLIND MODE (Inclusion Feature):** Using Web Audio API, distance to Planet X is converted to Beep Sound (Volume, Frequency, Stereo Pan). Visually impaired users can find it by hearing.
5.  Tech: HTML, CSS, JavaScript, Web Audio API, NASA API

**Why Simulation?** SPHEREx real infrared data (FITS) is not yet fully public in IRSA Archive. So we built the exact tool scientists WILL use.
